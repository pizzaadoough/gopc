# Give Our PHP Coffee

**Coffee in. Plaintext out of sight. ☕**

GOPC is a PHP source-code transformation tool designed to turn ordinary PHP scripts into a less human-readable output format.

Built for developers who love PHP, enjoy automation, and probably need another cup of coffee.

### 🛡️ Security Disclaimer

Code transformation is not automatically encryption or a guarantee of security.

Do not assume that transformed code cannot be reverse-engineered. Test the generated output in a controlled environment and keep backups of your original source files.

GOPC should only be used on code you own or are authorized to modify.
